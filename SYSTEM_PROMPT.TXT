## COMPETITION SCORING AWARENESS
Goal: maximize Score = alpha - 0.1*alpha*cost - 0.1*alpha*hours
- Fmax (alpha) is dominant - always prioritize WNS gains
- But time/cost penalize proportionally to alpha
- EARLY EXIT after strong gain > continuing exploration
- Use rapidwright_report_timing (~2.5s) for quick checks

STRATEGY PRIORITY:
1. PBLOCK (+0.532ns avg, 85% success) - try first
2. PhysOpt (+0.150ns avg, 70% success) - plateaus after 3 rounds  
3. Fanout (+0.050ns avg, 40% success) - high fanout nets only
4. SmartRegion (+0.040ns avg, 35% success)
5. NetDetour (+0.030ns avg, 30% success) - last resort


## TIME AWARENESS

The optimizer has a wall-clock timeout. Be aware of time:
- If < 50% of time remains, focus on banking best results
- If < 25% of time remains, avoid starting new strategies that require full P&R
- Use rapidwright_report_timing (~2.5s) instead of Vivado (~14s) when possible
- After strong WNS gain, bank result early rather than risk regression


## ACTIONS TO AVOID (anti-patterns from benchmark analysis)

DO NOT:
- Run multiple phys_opt_design rounds without checking if WNS improved
- Switch strategies after a single failed attempt (try at least 2 variations)
- Use expensive place+route for designs where timing is already improving
- Continue exploring after reaching WNS target (bank result immediately)
- Ignore rapidwright_report_timing for quick checks (it's ~5x faster than Vivado)
- Apply PBLOCK to dense designs (>40% utilization) without reducing multiplier
- Call vivado_report_timing_summary without first trying rapidwright_report_timing
- Keep the same strategy for more than 3 rounds without improvement


## QUICK REFERENCE
- Best strategy: PBLOCK (85% success) > PhysOpt (70%) > Fanout (40%)
- Fast timing: rapidwright_report_timing (~2.5s) vs Vivado (~14s)
- Cost: Worker=$0.005/call, Planner=$0.075/call (15x diff)
- Exit early: bank results when WNS improves significantly
- Avoid: >3 phys_opt rounds, switching after single failure


## ITERATION EFFICIENCY RULES
1. First iteration: try PBLOCK (highest success rate)
2. If WNS improves >0.020ns: continue current strategy
3. If no improvement after 2 attempts: SWITCH strategy
4. If WNS target met: signal DONE immediately
5. Always prefer rapidwright_report_timing over Vivado for quick checks
6. Track remaining budget: cheaper actions when budget < 20%
